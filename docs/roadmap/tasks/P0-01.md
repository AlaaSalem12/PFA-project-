# P0-01 — Git baseline + env cleanup
Repo: run in **backend** first, then repeat steps 1–3 in **frontend** · Model: Sonnet · Priority: MUST

## Context
Neither folder is a git repository. We need a safe baseline before any change. The backend `.env.example` uses different key names than `.env` and `env.ts`.

## Read only
- `.gitignore`, `.env.example`, `src/config/env.ts` (backend) · `.gitignore` (frontend)

## Do
1. `git init` (default branch `main`). Make sure `.gitignore` excludes: `node_modules/ dist/ .env .env.* !.env.example coverage/ *.log uploads/ *.tsbuildinfo`. (Frontend: keep `.env` ignored too, and add a `.env.example` with `VITE_API_URL=http://localhost:8081/api/v1`.)
2. Check that no secret is tracked: `git status` must not list `.env`.
3. `git add -A && git commit -m "chore: baseline"`.
4. Backend only: rename keys in `.env.example` to the ones the code really uses: `SMTP_PASSWORD`, `SMTP_FROM`, `FRONTEND_URL` (drop `SMTP_PASS`, `MAIL_FROM`, `APP_URL`), and set `PORT=8081`.
   In `env.ts` remove `SMTP_PASS`, `MAIL_FROM`, `APP_URL`; in `src/modules/mail/mail.service.ts` use `SMTP_PASSWORD`, `SMTP_FROM ?? SMTP_USER`, and `FRONTEND_URL` for links.
5. Backend only: add `LLM_BASE_URL`, `LLM_API_KEY`, `LLM_MODEL` (optional, empty) to `.env.example` and as `z.string().optional()` in `env.ts` (used in Phase 2).

## Acceptance
- `npx tsc --noEmit` passes. `git log` shows the baseline commit and a second commit `P0-01: env cleanup`.

## Don't
- Don't commit `.env`. Don't change any other code.
