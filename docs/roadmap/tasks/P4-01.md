# P4-01 — Backend production image
Repo: backend · Model: Sonnet · Priority: MUST · Depends: Phase 1–2 backend

## Read only
`Dockerfile`, `docker-compose.yml`, `package.json`, `tsconfig.json`, `src/app.ts` (CORS part), `src/config/env.ts`.

## Do
1. Move `prisma` from devDependencies to dependencies. The seed must be compiled to `dist/prisma/seed.js` (tsconfig already includes `prisma/**/*.ts` — verify `npm run build` emits it).
2. Rewrite the `Dockerfile` on `node:20-bookworm-slim` (avoids musl issues with bcrypt/Prisma):
   - Install `openssl` + `ca-certificates`.
   - Build stage: `npm ci`, `prisma generate`, `npm run build`, `npm prune --omit=dev`.
   - Runtime stage: copy `node_modules`, `dist`, `prisma/` (schema + migrations), `package.json`, `docker-entrypoint.sh`.
   - Non-root `node` user. `EXPOSE 8080`.
   - `HEALTHCHECK` using `node -e "fetch('http://localhost:8080/health').then(r=>process.exit(r.ok?0:1)).catch(()=>process.exit(1))"`.
3. `docker-entrypoint.sh`:
   - `npx prisma migrate deploy`.
   - If `SEED_ON_START=true` → `node dist/prisma/seed.js` (the seed is idempotent).
   - `exec node dist/src/server.js`.
   - Create `$UPLOADS_DIR/machines` and make sure it's owned by `node`.
4. CORS: support `CORS_ORIGIN=same-origin` → allow when the request `Origin` host equals the `Host` header (`X-Forwarded-Host` when behind the proxy). Use the cors delegate form `(req, cb)`. Keep the list mode for dev.
5. `.dockerignore`: `node_modules dist .env* coverage uploads eval/results* .git`.
6. `/health` also checks the DB (`SELECT 1`); on failure → 503 `{status:"degraded"}`.
7. Remove the old root `docker-compose.yml` api service. Keep only `postgres` for local dev and say so in a comment; production compose lives in the frontend repo `deploy/` (P4-02).

## Acceptance
`docker build -t metalworks-api .` succeeds (if Docker is available locally; if not, say so in PROGRESS.md). tsc + lint + tests pass.
