# P2-03 — Assistant API
Repo: backend · Model: Sonnet · Priority: MUST · Depends: P2-02

## Read only
`src/modules/assistant/*`, `src/app.ts`. Contract §10.

## Do
1. Routes `src/modules/assistant/assistant.routes.ts` mounted at `/api/v1/assistant`:
   - Chain: `authenticate, requirePasswordChange`.
   - Endpoints exactly as in §10. Message `content`: trimmed, 1–2000 chars.
2. A per-user rate limiter on POST messages: 30 per hour, `keyGenerator: req.user.id`. 429 in the standard error shape.
3. `GET /status` → `{enabled, model}`. When not enabled, POST messages → 503 ASSISTANT_UNAVAILABLE.
4. `GET /suggestions` → 4–6 example questions per role (FR + EN pairs or FR only — keep FR, the UI is French-first).
5. Audit ASSISTANT_MESSAGE with metadata `{conversationId, toolsUsed, latencyMs}` (not the message text).
6. GET messages returns only USER/ASSISTANT rows, mapped to `{id, role: "user"|"assistant", content, toolsUsed, createdAt}`.

## Acceptance
tsc + lint + tests (404 for other user's conversation, 503 when disabled, validation 400 for empty content).
Manual: put a Groq or Gemini key in `.env`, then with curl or REST client ask "Quelles machines sont en panne ?" and check the answer matches the seed data.
