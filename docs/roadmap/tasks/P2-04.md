## Do
1. `npm i react-markdown remark-gfm`.
   - `api/assistant.api.ts` for every §10 endpoint.
   - Types in `types/api.ts`: AssistantStatus, Conversation, ChatMessage.
2. `features/assistant/components/`:
   - `ChatThread`: message bubbles (user right, assistant left with a small bot avatar), auto-scroll to bottom, markdown with GFM tables (MUI-styled table, code, lists), a "Tools used" row of small outlined chips under assistant messages (translated tool labels), and an animated typing indicator while pending.
   - `ChatInput`: multiline, Enter = send, Shift+Enter = new line, 2000-char counter, disabled while pending.
   - `SuggestionChips`: from `/assistant/suggestions`, shown on an empty thread; click = send.
   - `AssistantUnavailable`: shown when `/status.enabled === false`.
3. `AssistantPage` (`/assistant`, all roles, lazy-loaded):
   - Left column: conversation list (new, select, delete with ConfirmDialog, relative dates). Right: thread + input.
   - Mobile (<900px): the list becomes a drawer.
   - URL `/assistant/:conversationId?` keeps the selected conversation.
4. `AssistantWidget`:
   - Mounted in AppLayout. A floating action button bottom-right (theme primary, `SmartToy` icon) on every page except `/assistant/*`.
   - Opens a 400×600 Paper panel (fullscreen on mobile) that reuses ChatThread/ChatInput on the most recent conversation, or creates one on first send.
   - Header with "Open full page" and close buttons.
   - The panel keeps its state when navigating between pages.
5. Behaviour:
   - Optimistic user message.
   - On error show an inline error under the message with "Retry". Map RATE_LIMITED and ASSISTANT_UNAVAILABLE to friendly text.
   - Invalidate the conversations list after each answer (title/updatedAt change).
6. Navigation: add "Assistant" (all roles, `SmartToy` icon) to `navigation.ts` with an i18n key.
   Put every new UI string in `fr.json` and `en.json` under an `assistant` namespace (French first).
7. Theme colors only, readable multi-line JSX, works in dark mode.
