# P1-11 — Frontend foundation
Repo: frontend · Model: **Opus** · Priority: MUST · Depends: backend P1-01, P1-02

## Context
- `api/client.ts`: when one token refresh is running, every other request that gets a 401 calls `logout()`. After P1-02 the refresh token rotates, so concurrent refreshes must share ONE promise.
- Error messages show axios text ("Request failed with status code 401").
- There are no shared table, dialog, toast or empty-state components.
- Search fires a request on every keystroke.

## Read only
`src/api/client.ts`, `src/store/authStore.ts`, `src/types/api.ts`, `src/app/providers.tsx`, `package.json`. Contract §0, §1.

## Do
1. `api/client.ts`:
   - Single-flight refresh: `let refreshPromise: Promise<string> | null`. All 401s await it, then retry once.
   - Logout + redirect only if the refresh fails.
   - Don't attach the token to public auth endpoints (keep the current logic).
   - Export `API_ORIGIN = new URL(baseURL, window.location.origin).origin` and `assetUrl(path)` (returns `data:`/`http` URLs unchanged, otherwise prefixes API_ORIGIN).
   - Default `baseURL` fallback becomes `/api/v1` (production uses the nginx proxy).
2. `api/errors.ts`:
   - `getErrorMessage(err, fallback?)` → server `message`, or friendly text for network error / 429 / 500.
   - `applyFieldErrors(err, setError)` for react-hook-form.
3. Toasts without a new dependency:
   - `store/toastStore.ts` (zustand queue) + `components/ToastHost.tsx` (MUI Snackbar + Alert) mounted in providers.
   - `toast.success(msg)` / `toast.error(msg)` helpers.
   - Default mutation `onError` in QueryClient → `toast.error(getErrorMessage(e))` unless `meta.silent`.
4. Shared components in `src/components/`:
   - `DataTable` wrapping `@mui/x-data-grid` (install `@mui/x-data-grid@^8`) in server mode. Props: rows, rowCount, loading, paginationModel, onPaginationModelChange, sortModel, onSortModelChange, columns, onRowClick.
   - `ConfirmDialog` (title, message, confirm label, danger flag, loading).
   - `EmptyState` (icon, title, text, action).
   - `FormDialog` (title, form id, submit label, loading, children).
   - `RoleGate` (`roles`, children).
5. Hooks:
   - `hooks/useDebouncedValue(value, 300)`.
   - `hooks/useUrlState()` to keep page/size/sort/search/filters in the query string.
6. `types/api.ts`: align with the contract (decimals as number, `fromStatus: MachineStatus | null`, SafeUser fields, Page). Add types for Employee, Department, Position, WorkOrder, Notification, Paged queries.
7. `utils/format.ts`: `formatDate`, `formatDateTime`, `formatEnum` (`replaceAll('_',' ')` + capitalize), `formatMoney` (TND).
