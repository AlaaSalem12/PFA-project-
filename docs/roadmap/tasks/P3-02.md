# P3-02 — Screenshot automation
Repo: frontend · Model: Sonnet · Priority: MUST · Depends: Phase 1 and 2 done, backend running with seed data

## Do
1. `npm i -D @playwright/test` and `npx playwright install chromium`.
2. `scripts/screenshots.ts` (run with `npx tsx scripts/screenshots.ts`). Base URL from `SHOT_BASE_URL` (default http://localhost:4200). Viewport 1440×900, light theme.
   - For each demo account (admin, hr, prod, tech, employee / Demo@1234; admin password from env `SHOT_ADMIN_PASSWORD`), log in through the UI and capture every page in that role's navigation.
   - Also capture: machine detail (each tab), the machine form, a user form dialog, a work order detail, the notifications popover, the assistant page with one answered question (only if `SHOT_ASSISTANT=1`), and the login page.
   - Plus 3 dark-mode shots (dashboard, machines, assistant) and 2 mobile shots (390×844: dashboard, machine detail).
3. Save to `docs/report/screenshots/<role>/<nn>-<page>.png`. Wait for network idle and hide the toast host before each shot.
4. Write `docs/report/screenshots/INDEX.md` listing file → what it shows (for captions).
