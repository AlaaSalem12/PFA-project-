# P2-06 — Streaming answers (COULD)
Repo: backend then frontend · Model: Sonnet · Priority: COULD

## Do
- Backend: `POST /assistant/conversations/:id/messages/stream` → SSE (`text/event-stream`). Events: `tool` {name}, `delta` {text}, `done` {assistantMessage}, `error` {message}. Use `stream: true` only for the final round (tool rounds stay non-streamed). Disable compression/buffering headers (`X-Accel-Buffering: no` for nginx).
- Frontend: use `fetch` + ReadableStream (EventSource can't send the Authorization header). Render deltas progressively and show "Using tool: …" while tools run. Fall back to the non-stream endpoint on failure.
