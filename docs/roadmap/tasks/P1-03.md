# P1-03 — Audit logging everywhere
Repo: backend · Model: Sonnet · Priority: MUST · Depends: P1-01

## Context
`src/common/audit.ts` has an `audit()` helper that is never called, so the Audit page is empty in real use.

## Read only
`src/common/audit.ts`, then the route/service files of: auth, users, machine, employee, organization. Contract §9 (action names).

## Do
1. Make `audit()` fire-and-forget safe: wrap in try/catch, `console.error` on failure, never throw.
2. Add a helper `auditFrom(req, {action, entity, entityId?, metadata?})` that takes `userId` from `req.user` and `ip` from `req.ip`.
3. Call it after every successful write, using the action names in §9:
   - auth: login (success + failed, failed has `metadata: {username}` and no userId), logout, password changed, password reset.
   - users: created, updated (metadata: changed fields), enabled/disabled, password reset, unlocked (when it exists), deleted.
   - employees, departments, positions: created/updated/deleted.
   - machines: created, updated (changed field names), deleted, status changed (`{from, to, comment}`), image updated, note added.
4. Metadata must never contain passwords, tokens or SSN.
5. Audit list route: add filters `userId`, `from`, `to` (ISO dates) per §9.

## Acceptance
- tsc + lint + tests pass. Add one test: creating a user calls `prisma.auditLog.create` with action USER_CREATED.

## Don't
- Don't add audit to read-only GET routes.
